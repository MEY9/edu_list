# Edu List — 教育与可用于教育的 GitHub 项目库

面向教师、教育产品开发者和培训机构，收集教育原生项目以及可用于教育的应用、开发组件和课程资源。按 Star 层级与教育用途交叉组织，保留准确数字、数据时间、原始简介和检索来源。

[Star 分层](#star-分层) · [分类导航](#分类导航) · [全部项目](lists/all.md) · [待审核](lists/candidates.md) · [归档记录](lists/retired.md) · [推荐项目](https://github.com/MEY9/edu_list/issues/new/choose)

- **项目库**：批量检索一般从 Star ≥ 100 开始；教育原生软件及可用于教育的工具都可收录。少量低星项目保留明确用途记录。
- **已核对高星精选**：Star ≥ 1,000，完成上游资料核对，仓库未归档／禁用。关注度和核对深度独立展示。
- **教育原生**：面向教学、学习或学校业务；**可用于教育**：通用应用或组件，可评估整合到教学业务。
- 批量条目标记为“元数据收集”，依据公开描述与主题初步分类；中文教育用途为分类建议，未逐项阅读 README、部署或验证教学效果，后续可纠正分类及提升核对深度。
- Star 反映关注度；许可证标识来自 API，实际许可与费用以各项目、模型、内容和外部服务的上游条款为准。
