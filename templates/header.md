# Edu List — 教育高星 GitHub 项目精选

面向教师、教育产品开发者和培训机构，按教学用途整理高 Star 项目，记录使用场景、成本、部署方式和核对来源。

[分类导航](#分类导航) · [观察清单](lists/watchlist.md) · [待审核](lists/candidates.md) · [归档记录](lists/retired.md) · [推荐项目](https://github.com/MEY9/edu_list/issues/new/choose)

- 主清单门槛：Star ≥ **1,000**，已完成资料核对，仓库未归档／禁用。
- **教育原生**：面向教学或学习；**可用于教育**：通用工具，需要课程内容或教学功能整合。
- 核对深度单独记录。初始条目由 Codex 辅助阅读上游资料，未经逐项部署或课堂验证，未验证教学效果。
- Star 反映关注度；许可证标识只是 API 识别结果。各项目、模型、课程内容与外部服务以其上游条款为准。
